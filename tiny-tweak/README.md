# Tiny Tweak

**Kills:** "small change, small work."

A working coffee-run order page and six client requests, all "quick ones." Guess Small, Medium
or Large for each; every card reveals the real size — spots touched, approximate lines, and the
ripple of consequences. The requests are authored so instinct misleads: the button-colour change
really is one line, but the one-word wording change touches three places ("miss one and the
product disagrees with itself"), and the euros request contains a question no code can answer —
whose exchange rate? One request is genuinely tiny on purpose: the lesson is measurement, not
paranoia. Closing move: before saying "just quickly," ask the agent *what does this actually
touch?* — the inside is invisible, but it answers questions.

size-guess column is this toy played for real.
