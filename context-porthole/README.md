# Context Porthole

**Kills:** "it sees what I see."

You know seven things about this project. The agent is about to do a task for it — and each
session it knows exactly two things: what's written in the folder, and what's in your message.
Send the task through the porthole and get back work with three mistakes, every one tagged the
same way: *the fact that would have prevented this was in your head.* It didn't ignore you — it
never heard you. Click a fact to write it into the right file and watch its mistake vanish on
the automatic re-send. One chip refuses to be written — *"you'll know premium when you see
it"* — because judgement doesn't fit through any porthole, and that one rides along as you.

**Pairs with:** Lab 6 — *Teach the Intern* (fix the folder, not the chat) and Lab 7 — *Trust,
Then Verify* (`programming-labs`).

Built from [`SPEC.md`](SPEC.md), like every toy in this collection. Add `?present` for a
projector.
